# YouTube 接続の初期設定（初回のみ）

MatchQueue が YouTube のライブチャットを読んだり投稿したりするには、
Google Cloud で「自分専用の接続設定（OAuth クライアント）」を 1 つ作る必要があります。所要 10 分程度・無料です。

## 1. Google Cloud プロジェクトを作る

1. <https://console.cloud.google.com/> を開き、配信に使う Google アカウントでログイン
2. 画面上部のプロジェクト選択 →「新しいプロジェクト」→ 名前は `MatchQueue` など → 作成

## 2. YouTube Data API v3 を有効にする

1. 左メニュー「API とサービス」→「ライブラリ」
2. `YouTube Data API v3` を検索 →「有効にする」

## 3. OAuth 同意画面（Google Auth Platform）を設定する

1. 「API とサービス」→「OAuth 同意画面」
2. ユーザーの種類：**外部** / アプリ名：`MatchQueue` / サポートメール：自分のアドレス
3. 「対象（テストユーザー）」に **配信に使う Google アカウント** を追加
   - Bot 用サブアカウントで投稿したい場合は、そのアカウントも追加

> 公開ステータスが「テスト」のままだと、**ログインは 7 日ほどで切れます**。
> 切れた場合はアプリの設定画面で「再ログイン」を押せば復帰します。

## 4. OAuth クライアント ID を作る

1. 「API とサービス」→「認証情報」→「認証情報を作成」→「OAuth クライアント ID」
2. アプリケーションの種類：**デスクトップ アプリ**
3. 作成後に表示される **クライアント ID** と **クライアント シークレット** を控える

## 5. MatchQueue に登録する

1. MatchQueue の「設定」→「YouTube 接続」にクライアント ID とシークレットを貼り付けて「保存」
2. 「Google でログイン」→ ブラウザで配信用アカウントを選び、権限を許可
   - 「このアプリは Google で確認されていません」と出たら「詳細」→「MatchQueue（安全ではないページ）に移動」
     （自分で作ったアプリなので問題ありません）
3. 「接続が完了しました」と表示されたらブラウザを閉じて OK

## 6. 配信ごとの操作

1. YouTube Studio で配信を開始（または予約）しておく
2. MatchQueue の「設定」→「配信を探す」→ 対象の配信を選ぶ
   - 見つからない場合は配信 URL を「URL から指定」に貼って「読み込む」
3. 「チャットに接続」→ ヘッダーが「チャット取得中」になれば準備完了

## API 使用量について

- YouTube Data API は 1 日あたり 10,000 ユニットが上限（太平洋時間 0 時にリセット）
- 目安：チャット取得 1 回 ≒ 5、投稿 1 回 ≒ 50
  - 5 秒間隔で 2 時間取得 ≒ 7,200 ＋ 投稿 30 回 ≒ 1,500
- 足りない場合は「取得間隔の下限」を広げる、「受付などの返信」を「まとめて投稿」または「返信しない」にする
- 実際の使用量は Google Cloud Console の「API とサービス」→「割り当て」で確認できます
  （アプリ内の表示は推定値です）
