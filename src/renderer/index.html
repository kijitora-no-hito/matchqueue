        わんコメ連携 かんたん・おすすめ

        コメントビューア「わんコメ」が受け取ったコメントを MatchQueue に転送します。Google Cloud の設定は不要です。 チャットへの投稿はできないため、受付などの返信は配信オーバーレイにお知らせとして表示されます。

        1. わんコメを起動した状態で「わんコメにプラグインを入れる」を押す
        2. わんコメの「プラグイン」画面（「連携」画面とは別）で「MatchQueue 連携」のスイッチをオンにする（出てこない場合は「再読み込み」かわんコメを再起動）
        3. わんコメで配信のコメント取得を開始すると、ここが「受信中」になります

        YouTube 接続（上級者向け・任意）

        チャットへの自動投稿（告知・受付の返信）もしたい場合に使います。初回のみ、Google Cloud で「OAuth クライアント ID（デスクトップアプリ）」を作成して貼り付けてください。手順は docs/youtube-setup.md を参照。

        チャット取得・投稿

        既定の API 上限は 1 日 10,000。取得 1 回 ≒ 5、投稿 1 回 ≒ 50 を目安に表示しています。
